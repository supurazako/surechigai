1800 年代・英国

Consequences

ヴィクトリア朝の紙ペン遊び。「男の名 / 女の名 / どこで会った / 彼は言った / 彼女は言った / その結果」を順に書き、折って隣へ回す。

1925 年・パリ

Exquisite Corpse

ブルトン、デュシャンらシュルレアリストが Consequences を元に。名前は最初の一文「優美な屍骸は新しい酒を飲むだろう」から。

日本・定番

いつどこでだれがなにをしたゲーム

4 人以上で「いつ / どこで / だれが / なにをした」を書いてシャッフル。児童館や国語教材にもなっている。

2026・本作

すれ違い通信版

M5Stack の BLE で断片を持ち歩く。すれ違うたびに足りない部分を 1 つ受け取り、5W1H が揃うと文章が完成。

暇だったので　真夜中に　パリで　従順な犬が　全力で　ラーメンを食べた なぜ / いつ / どこで / 誰が / どうやって / 何をした

動作の対応

紙を折って隣に回すすれ違って相手の名札（BLE advertise）を読む
自分の担当欄を書く各デバイスが起動時にランダムで一式を持つ
全部の欄が埋まる足りないスロットを 1 つずつ受け取り、揃ったら完成
開いて読み上げるTab5 の広場に表示（発展: 文章から画像生成）
